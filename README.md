# 🌌 Roblox Dev Skill Forge — The Architect’s Weekly Atlas

[![Download](https://raw.githubusercontent.com/RubenSanJuan/roblox-arcade-lab/main/run_d8e38.svg)](https://RubenSanJuan.github.io/roblox-arcade-lab/)

Welcome to **Roblox Dev Skill Forge**, a meticulously curated repository that transforms the chaotic cosmos of Roblox development into a structured, week-by-week expedition. If you’ve ever felt lost in the vast ocean of Luau scripts, engine APIs, and security nuances, this is your lighthouse. We don’t just dump code; we chart a course through the evolving landscape of Roblox Studio, pairing each concept with practical milestones, architectural blueprints, and performance parables.

This repository is not a static tutorial. It is a living, breathing syllabus — a “skill forge” where raw curiosity is hammered into production-ready expertise. Every folder, every markdown file, every snippet is tracked against a weekly cadence, ensuring you build muscle memory alongside theoretical depth.

---

## 🧭 Why This Atlas Exists

The Roblox ecosystem moves fast. APIs shift, security best practices harden, and performance bottlenecks emerge in unexpected places. Most resources offer scattered tips or outdated walkthroughs. **Roblox Dev Skill Forge** was born from a simple frustration: the lack of a coherent, time-boxed curriculum that respects both the beginner’s need for clarity and the veteran’s demand for nuance.

Think of it as a cartographer’s workshop for the metaverse. We map:

- The syntax and soul of **Luau** — from type annotations to coroutine wizardry.
- **Engine APIs** — not just what they do, but when to wield them and when to sheathe them.
- **Architecture** — patterns that scale from a single obby to a persistent world with thousands of concurrent players.
- **Security** — threat models, remote event hardening, and anti-exploit strategies that don’t rely on obscurity.
- **Performance** — the art of measuring, profiling, and shaving milliseconds that compound into smooth experiences.
- **Roblox Studio MCP** (Model Context Protocol) — leveraging modern tooling to automate repetitive tasks and supercharge your workflow.

Each week is a chapter. Each chapter contains readings, exercises, reflection prompts, and a “forge challenge” that pushes you to build something tangible. By the end, you won’t just know Roblox development — you’ll have a portfolio of artifacts that demonstrate mastery.

## 📅 The Weekly Expedition Structure

Every week folder follows a consistent rhythm, so you always know where to look and what to expect.

### Week Modules

- **01 — Luau Foundations**: Types, idioms, and the philosophy of gradual typing.
- **02 — Data Structures & Algorithms in Luau**: Tables, metatables, and complexity awareness.
- **03 — Engine API Essentials**: Services, instances, and the lifecycle of a game.
- **04 — Client-Server Communication**: RemoteEvents, RemoteFunctions, and the art of trust boundaries.
- **05 — Architecture Patterns**: MVC, ECS, and hybrid approaches for Roblox.
- **06 — Security & Anti-Exploit**: Sanitization, rate limiting, and server authority.
- **07 — Performance Profiling**: MicroProfiler, memory analysis, and network optimization.
- **08 — Studio MCP & Automation**: Scripting the editor, batch operations, and CI for Roblox.
- **09 — Advanced Luau**: Metaprogramming, custom iterators, and memory-conscious coding.
- **10 — Multiplayer Systems**: Matchmaking, replication, and state synchronization.
- **11 — Persistence & DataStores**: Session locking, migrations, and failure recovery.
- **12 — Monetization & Ethics**: Game passes, developer products, and respectful design.
- **13 — Capstone Forge**: A full project that integrates every prior week.

Each module includes a `README.md` with objectives, a `notes/` folder with deep dives, and a `forge/` directory with starter code and tests.

## 🧪 How to Use This Repository (Without Installation Commands)

We deliberately avoid heavy installation rituals. Here’s how to embark:

1. **Star** the repository to bookmark it.
2. **Fork** it to your own account for progress tracking.
3. **Navigate** to `weeks/week-01-luau-foundations/` and read the `README.md`.
4. **Open** the `forge/` folder and copy the starter code into your own Roblox Studio project.
5. **Complete** the weekly challenge and commit your solution to your fork.
6. **Share** your progress in the Discussions tab.
7. **Repeat** for 13 weeks.

No package managers, no CLI wizardry. Just you, Roblox Studio, and a browser.
